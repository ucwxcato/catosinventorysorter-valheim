# Changelog

## 0.1.0

- Sort player inventory by total stack weight or stack quantity.
- Keep the hotbar, equipped items, and bound items in their current positions.
- Add an in-game sort button and F6 shortcut.
- Apply config file edits while the game is running.
- Keep arrows, armor, and food fixed in their current inventory slots while sorting.
- Add configurable special-item handling: ignore arrows, armor, and food or sort them first in a configurable order.
